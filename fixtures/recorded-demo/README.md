# Recorded investigation fixture

The byte-pinned package contains captured public CPSC snapshots, synthetic lots,
original v6 run metadata, structured proposals, native tool hashes and usage.
It is replayed as recorded evidence, never as a new model response.

The loader checks SHA-256, prompt/policy versions and the original scoped context.
It only installs into an empty instance with inference disabled. The current
validator revalidates the captured proposals. Original source-report filenames
and hashes inside the fixture are provenance labels, not required runtime files.

Use a separate empty instance for this course. It cannot be mixed with imported
inventory snapshots or used to replenish previously simulated sales. The local
sale/shipment simulator never modifies an external inventory system.
