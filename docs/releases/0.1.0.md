# 0.1.0 — contest evaluation

Recall-to-Inventory Bridge connects real US CPSC recall evidence to synthetic
inventory snapshots, using actual IRIS Interoperability and native AI Hub. The
existing inventory system retains authority over stock, sales and shipments.

- Import CSV/JSON with mapping previews, stable source IDs and idempotent retries.
- Discover CPSC candidates from reviewed product terms, then acquire selected evidence.
- Investigate with a scoped native agent when a verified provider is explicitly enabled.
- Validate source quotes, product conditions and input versions before returning advice.
- Export authenticated, versioned advisory JSON/CSV to the supplied review-worklist example.
- Optionally repeat source checks through the custom IRIS adapter. Automatic AI is a separate opt-in.

Start with the [first-visit guide](../first-visit.md) and
[98-second operation demo](https://www.youtube.com/watch?v=kQNJ_kUx9tA).
The snapshot course requires no model API key. A separate recorded course
revalidates genuine historical proposals and clearly labels their provenance.

The current target is **AI Hub Community 2027.1.0AI.109.0**. Obtain the authorized
EAP image privately from InterSystems; no base image, derived image, credential
or data volume is included in this release. Original code is **MPL 2.0**.

See [verification scope](../verification.md) for portable tests, real native AI
investigations and source/archive IPM installation. Public registry installation
is a separate route and must be checked independently.

This bounded evaluation handles 100 inventory records, eight discovery queries
and 40 retrieved candidates per search. Coverage is incomplete: candidates and
zero results never establish general product safety. Monitoring requires a
running host. No external stock writeback connector is provided.
