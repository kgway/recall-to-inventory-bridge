# Technical verification data

The CPSC response directories contain captured official public recall data used
by the synthetic examples. Source URLs and capture metadata are in their manifests.

The IRIS JSON files are technical extracts from genuine native execution,
scheduled-audit, trace, package-installation and regression checks. Original
timestamps/run IDs are retained; inspecting an extract does not start inference.
The fixture and tests use synthetic inventory and do not update external stock.

See [verification scope](../../docs/verification.md) and
[trace reproduction](../../docs/traceability.md).
