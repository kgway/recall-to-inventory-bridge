1. Import an inventory snapshot

CSV or JSON from an ERP, WMS or spreadsheet. The bridge stores a local copy; it has no connection or write credentials to your inventory system. Up to 100 records in this evaluation workspace.

Column mapping and import options

Common column names are detected. Map canonical fields to your exact headers when needed, for example {"sku":"Item Code","name":"Description","quantity":"On Hand"}. Unmapped columns are ignored. Supply external_id, or distinguish each SKU / lot_number / location combination.

2. Find relevant CPSC notices

Review the public product terms before retrieval. Search uses the official CPSC API, requires no AI key and makes no inventory changes. At most eight queries per search; results are incomplete candidate retrieval.

3. Hand advice to your existing workflow

Authenticated JSON/CSV feeds include source record references, evidence versions and assessment scope. No sale, shipment or quantity update is sent to an external system. An unassessed or unmatched search is never an assurance of safety.

4. Keep checking for changes

Run an audit now or enable recurring checks. Each audit searches CPSC, refreshes up to five selected notices, and records new candidates, changed evidence and advice. New candidates go to review; they are not automatically selected or treated as recalled.

Review the search terms in step 2 before enabling periodic checks. This also permits those public product terms from future inventory captures. No SKU, external ID, warehouse or quantity is sent to CPSC. No external inventory action is performed.
